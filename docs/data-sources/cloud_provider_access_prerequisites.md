# redpanda_cloud_provider_access_prerequisites (Data Source)

Data source for the values an IAM role trust policy needs before a `redpanda_cloud_provider_access` can use the role

~> **Preview:** cloud provider access is a preview feature of Redpanda Cloud. Your organization must have cross-account BYOC enabled; contact Redpanda support to enable it.

<!-- schema generated by tfplugindocs -->
## Schema

### Required

- `cloud_provider` (String) Cloud provider to get prerequisites for. Only `aws` is supported.

### Read-Only

- `aws` (Attributes) AWS prerequisites. Set when cloud_provider is `aws`. (see [below for nested schema](#nestedatt--aws))

<a id="nestedatt--aws"></a>
### Nested Schema for `aws`

Read-Only:

- `external_id` (String) External ID to require in the IAM role trust policy's `sts:ExternalId` condition.
- `principal_arn` (String) ARN of the Redpanda principal that assumes the role. Allow it as the `Principal` in the IAM role trust policy.

## Example Usage

```terraform
data "redpanda_cloud_provider_access_prerequisites" "aws" {
  cloud_provider = "aws"
}

output "trust_principal_arn" {
  value = data.redpanda_cloud_provider_access_prerequisites.aws.aws.principal_arn
}

output "trust_external_id" {
  value = data.redpanda_cloud_provider_access_prerequisites.aws.aws.external_id
}
```
